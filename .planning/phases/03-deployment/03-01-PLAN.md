  <name>Task 1: Create .gitattributes and wwwroot static files for GitHub Pages</name>
  <files>

  <action>
Create four files:

1. **`.gitattributes`** (repo root) — Prevent Git line-ending conversion that breaks Blazor's boot integrity check:
```
*.js binary
*.wasm binary
```
This MUST be committed BEFORE the app assets are deployed to the gh-pages branch. Without it, Git may convert CRLF to LF in JS files during checkout, changing SHA-256 hashes and causing Blazor integrity check failure.

2. **`NetStarter/NetStarter/wwwroot/.nojekyll`** — Empty file (zero bytes). Prevents GitHub Pages Jekyll processing from stripping the `_framework/` directory. Without this, the deployed app shows a blank page because `_framework/blazor.webassembly.js` gets 404.

3. **`NetStarter/NetStarter/wwwroot/CNAME`** — Single line containing `starter.dotnetth.com` (no trailing newline). This file gets included in the publish output and deployed to gh-pages, preserving the custom domain setting across deploys. The peaceiris action also sets this via `cname:` param as a belt-and-suspenders approach.

4. **`NetStarter/NetStarter/wwwroot/404.html`** — Exact copy of `index.html`. This is a safety net for any direct URL access. Since the app is truly single-page with query parameter state (no client-side routing), the 404.html does NOT need SPA redirect JavaScript — just a copy of index.html is sufficient. The Blazor app boots normally and reads query params.
  </action>
  <verify>
    <automated>test -f .gitattributes && grep -q "*.js binary" .gitattributes && test -f NetStarter/NetStarter/wwwroot/.nojekyll && test -f NetStarter/NetStarter/wwwroot/CNAME && grep -q "starter.dotnetth.com" NetStarter/NetStarter/wwwroot/CNAME && test -f NetStarter/NetStarter/wwwroot/404.html && diff NetStarter/NetStarter/wwwroot/index.html NetStarter/NetStarter/wwwroot/404.html && echo "PASS"</automated>
  </verify>
  <done>.gitattributes has *.js and *.wasm binary rules; wwwroot contains .nojekyll (empty), CNAME (starter.dotnetth.com), and 404.html (identical to index.html)</done>
</task>

<task type="auto">
  <name>Task 2: Create GitHub Actions CI/CD workflow</name>
  <files>.github/workflows/deploy.yml</files>
  <action>
Create `.github/workflows/deploy.yml` with the following structure:

**Triggers:**
- `push` to `main` branch (full build + test + deploy)
- `pull_request` to `main` branch (build + test only, no deploy)

**Permissions:**
- `contents: write` (required for peaceiris to push to gh-pages branch)

**Concurrency:**
- Group: `${{ github.workflow }}-${{ github.ref }}`
- Cancel in-progress: true

**Job 1: `build` (runs on all triggers)**
1. `actions/checkout@v4`
2. `actions/setup-dotnet@v5` with `dotnet-version: '10.0.x'`
3. `actions/cache@v4` for NuGet packages:
   - path: `~/.nuget/packages`
   - key: `${{ runner.os }}-nuget-${{ hashFiles('**/*.csproj') }}`
   - restore-keys: `${{ runner.os }}-nuget-`
   (Using actions/cache because project has no packages.lock.json — setup-dotnet cache: true requires lock files)
4. `dotnet restore NetStarter/NetStarter.sln`
5. `dotnet build NetStarter/NetStarter.sln -c Release --no-restore`
6. `dotnet test NetStarter/NetStarter.sln -c Release --no-build --verbosity normal`
   (Will succeed vacuously if no test projects exist; ready for when they're added)

**Job 2: `deploy` (only on push to main)**
- `needs: build`
- `if: github.ref == 'refs/heads/main' && github.event_name == 'push'`
- Steps:
  1. `actions/checkout@v4`
  2. `actions/setup-dotnet@v5` with `dotnet-version: '10.0.x'`
  3. `actions/cache@v4` for NuGet (same config as build job)
  4. `dotnet publish NetStarter/NetStarter/NetStarter.csproj -c Release -o publish`
  5. Add `.nojekyll` to publish output: `touch publish/wwwroot/.nojekyll`
     (Belt-and-suspenders: .nojekyll is in wwwroot source AND explicitly added to publish output)
  6. `peaceiris/actions-gh-pages@v4` with:
     - `github_token: ${{ secrets.GITHUB_TOKEN }}`
     - `publish_dir: ./publish/wwwroot`
     - `cname: starter.dotnetth.com`
     - `force_orphan: true`

Do NOT:
- Use `actions/deploy-pages` (native flow) — incompatible with gh-pages branch deployment per locked decision
- Add `SteveSandersonMS/ghaction-rewrite-base-href` — not needed for custom domain at root `/`
- Use `setup-dotnet` built-in `cache: true` — requires packages.lock.json which doesn't exist
  </action>
  <verify>
    <automated>test -f .github/workflows/deploy.yml && grep -q "peaceiris/actions-gh-pages@v4" .github/workflows/deploy.yml && grep -q "dotnet-version.*10.0" .github/workflows/deploy.yml && grep -q "cname: starter.dotnetth.com" .github/workflows/deploy.yml && grep -q "github.ref == 'refs/heads/main'" .github/workflows/deploy.yml && echo "PASS"</automated>
  </verify>
