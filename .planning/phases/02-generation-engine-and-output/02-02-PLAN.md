    <AnalysisLevel>latest-recommended</AnalysisLevel>

**SlnxGenerator.cs** — Static class `SlnxGenerator` in `NetStarter.Services.Generation`. Method `string Generate(ProjectConfiguration config)` that returns .slnx XML content.

Project paths vary by architecture:
- **CleanArchitecture**: `src/{Name}.Domain/{Name}.Domain.csproj`, `src/{Name}.Application/{Name}.Application.csproj`, `src/{Name}.Infrastructure/{Name}.Infrastructure.csproj`, `src/{Name}.Api/{Name}.Api.csproj`
- **VerticalSlice**: `src/{Name}/{Name}.csproj`
- **SimpleLayered**: `src/{Name}/{Name}.csproj`
- If `IncludeXUnit`: `tests/{Name}.Tests/{Name}.Tests.csproj`
- If `IncludeTestcontainers && Database.HasValue`: `tests/{Name}.IntegrationTests/{Name}.IntegrationTests.csproj`
- If `IncludeDotNetAspire`: `src/{Name}.AppHost/{Name}.AppHost.csproj`, `src/{Name}.ServiceDefaults/{Name}.ServiceDefaults.csproj`

Use `StringBuilder` with `AppendLine`. XML format: `<Solution>` root, `<Project Path="..." />` for each. Add `<Folder Path="src/" />` and `<Folder Path="tests/" />` entries if those folders have projects.

**CsprojGenerator.cs** — Static class `CsprojGenerator` in `NetStarter.Services.Generation`. Multiple methods:

1. `string GenerateWebProject(ProjectConfiguration config, List<string> additionalPackages = null)` — For WebApi/MinimalApi: SDK = `Microsoft.NET.Sdk.Web`, TFM from config, nullable enable, implicit usings enable, TreatWarningsAsErrors true, AnalysisLevel latest-recommended (per locked decision). PackageReferences added conditionally based on config selections.

2. `string GenerateClassLibrary(ProjectConfiguration config, string projectSuffix, List<string> packages = null)` — For Domain/Application/Infrastructure projects in Clean Architecture: SDK = `Microsoft.NET.Sdk`, same property group. Optional package references.

3. `string GenerateTestProject(ProjectConfiguration config, string mainProjectPath)` — For xUnit: SDK = `Microsoft.NET.Sdk`, IsPackable false. Packages: xunit, xunit.runner.visualstudio, FluentAssertions, Microsoft.NET.Test.Sdk, coverlet.collector. ProjectReference to the main project.

4. `string GenerateConsoleProject(ProjectConfiguration config)` — For Console type: SDK = `Microsoft.NET.Sdk`, OutputType Exe.

5. `string GenerateWorkerProject(ProjectConfiguration config)` — For WorkerService: SDK = `Microsoft.NET.Sdk.Worker`, package Microsoft.Extensions.Hosting.

6. `string GenerateIntegrationTestProject(ProjectConfiguration config, string mainProjectPath)` — For Testcontainers integration tests: SDK = `Microsoft.NET.Sdk`, IsPackable false. Packages: xunit, xunit.runner.visualstudio, FluentAssertions, Microsoft.NET.Test.Sdk, coverlet.collector (same as unit test project), PLUS Testcontainers packages based on config.Database: `Testcontainers.PostgreSql` if PostgreSQL, `Testcontainers.MsSql` if SQL Server. Also include `Microsoft.EntityFrameworkCore` (for DbContext reference in tests). ProjectReference to the main project (same as GenerateTestProject).

7. `string GenerateAspireAppHostProject(ProjectConfiguration config)` — SDK = `Aspire.AppHost.Sdk/9.2.0`, IsAspireHost true, OutputType Exe, ProjectReference to main API project.

7. `string GenerateAspireServiceDefaultsProject(ProjectConfiguration config)` — SDK = `Microsoft.NET.Sdk`, packages for resilience and service discovery.

All methods use `NuGetVersionMap.GetPackageVersion()` and `NuGetVersionMap.GetTargetFramework()` for version resolution. Use raw string literals (triple-quote) for XML template readability.

Note: CsprojGenerator depends on NuGetVersionMap from Plan 02-01 (Wave 1). Since this plan is Wave 2 (depends_on: [02-01]), NuGetVersionMap.cs is guaranteed to exist before CsprojGenerator.cs compiles. CsprojGenerator references NuGetVersionMap as a static class (no DI needed).

**StaticFileGenerator.cs** — Static class `StaticFileGenerator` in `NetStarter.Services.Generation`. Two methods:

1. `string GenerateGitignore()` — Standard .NET .gitignore content. Include patterns for: bin/, obj/, .vs/, *.user, *.suo, .idea/, *.DotSettings.user, publish/, logs/, appsettings.*.local.json. This is a static template — same for all configurations.

2. `string GenerateEditorconfig()` — Standard .NET .editorconfig with root = true, charset utf-8-bom for C# files, indent_style space, indent_size 4, end_of_line crlf for .cs/.csproj files. Include dotnet naming conventions: PascalCase for public members, camelCase with _ prefix for private fields. This is a static template.

Use raw string literals for clean multi-line content.

**AppSettingsGenerator.cs** — Static class `AppSettingsGenerator` in `NetStarter.Services.Generation`. Two methods:

1. `string GenerateAppSettings(ProjectConfiguration config)` — Produces appsettings.json with conditional sections:
   - Always: `"Logging": { "LogLevel": { "Default": "Information", "Microsoft.AspNetCore": "Warning" } }`
   - Always: `"AllowedHosts": "*"`
   - If EF Core + PostgreSQL: `"ConnectionStrings": { "DefaultConnection": "Host=localhost;Database={Name};Username=postgres;Password=postgres" }`
   - If EF Core + SQL Server: `"ConnectionStrings": { "DefaultConnection": "Server=localhost;Database={Name};Trusted_Connection=true;TrustServerCertificate=true" }`
   - If JWT: `"Jwt": { "Issuer": "https://localhost", "Audience": "https://localhost", "Key": "YOUR-SECRET-KEY-REPLACE-WITH-A-SECURE-VALUE-AT-LEAST-32-CHARS" }`
   - If Serilog: `"Serilog": { "MinimumLevel": { "Default": "Information", "Override": { "Microsoft.AspNetCore": "Warning" } }, "WriteTo": [{ "Name": "Console" }, { "Name": "File", "Args": { "path": "logs/log-.txt", "rollingInterval": "Day" } }] }`

   Build the JSON using a `Dictionary<string, object>` and serialize with `System.Text.Json.JsonSerializer.Serialize()` with `JsonSerializerOptions { WriteIndented = true }`. This avoids manual string concatenation for nested JSON.

2. `string GenerateAppSettingsDevelopment(ProjectConfiguration config)` — Minimal development overrides:
   - `"Logging": { "LogLevel": { "Default": "Debug", "Microsoft.AspNetCore": "Information" } }`
   - If Serilog: override `"Serilog": { "MinimumLevel": { "Default": "Debug" } }`

Same JSON serialization approach.
